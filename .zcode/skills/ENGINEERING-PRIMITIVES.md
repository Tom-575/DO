# Engineering primitives

This directory includes selected engineering Skills migrated from the Matt
Skill collection located at `D:/Project/SDLC_Claude/skills/skills/engineering`
at migration time. They are bundled as implementation primitives for the
`claude-sdlc` lifecycle Skills (Plan, Design, Build, Test, and Maintain).

These Skills remain independently named and are not lifecycle stages. The
lifecycle Skills own sequencing, artifact contracts, and human gates; these
primitives provide focused engineering methods when a stage needs them.

Migrated primitives:

- `triage`
- `research`
- `domain-modeling`
- `prototype`
- `codebase-design`
- `implement`
- `tdd`
- `code-review`
- `diagnosing-bugs`
- `improve-codebase-architecture`

The source material's local instructions and supporting files were preserved.
Review upstream changes before manually synchronizing a future revision.
