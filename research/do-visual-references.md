# DO 视觉参考调研

> 目的：为 DO 的完整视觉与交互重构寻找可借鉴的产品语言。以下案例借鉴的是构图、节奏、状态变化和内容组织原则，不复制品牌资产、文案、图标或具体页面。

## 先给结论

DO 不适合继续沿用“首页 + 卡片 + 底部 Tab”的工具型骨架。更有潜力的方向是：

1. 用一个有情绪的视觉场景建立第一印象，但让内容和动作保持清晰。
2. 让一个核心对象在输入、建议、行动、记录之间连续变形。
3. 让记录像个人出版物，而不是任务日志或社交信息流。
4. 导航退到空间边缘，通过手势、浮动入口或上下文出现，而不是固定横条。

## 参考一：Apple Journal

- 官方入口：[Apple Journal](https://www.apple.com/ios/ios-17/journal/)
- 官方设计语境：[Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/)

### 可见特征

- 以“今天发生过什么”为内容中心，而非任务或社交指标。
- 文字、照片、地点、音乐等内容被组织成一条私人叙事。
- 视觉留白较多，系统控件退到次要层级，内容本身成为主角。
- 记录入口低压力，允许用户从一个片段开始，而不是填写完整表单。

### 对 DO 的借鉴

- 记录应该支持“只有一句话也成立”，不要要求用户完成一套发布流程。
- 首页可以展示最近一页生活，而不是展示多个待办项目。
- 用户的原始话语要被保留，AI 只提供整理，而不是替用户制造内容。

### 避免抄袭

- 不复制 Journal 的系统卡片、推荐提示、图标和 iOS 视觉细节。
- DO 的差异应来自“念头到最小行动”的闭环，而不是做成另一个日记 App。

## 参考二：Day One

- 官方产品页：[Day One](https://dayoneapp.com/)
- 官方功能页：[Day One Features](https://dayoneapp.com/features/)

### 可见特征

- 把日记定位成长期积累的个人档案，强调时间、地点和媒体的组合。
- 记录可以很短，也可以包含照片、视频和音频，不强迫一种内容形态。
- 视觉上重视阅读体验，记录之间有明显的时间秩序，但不会像项目管理列表。

### 对 DO 的借鉴

- “已记录”是内容生命周期，不等于“任务完成”。这与 DO 的产品原则一致。
- 记录页可采用不规则的编辑编排：文字札记、单图故事、组图故事拥有不同版式。
- 需要有“回看”的愉悦感，让用户想积累，而非只想打卡。

### 避免抄袭

- 不使用其时间轴、日历视图或品牌色作为默认结构。
- DO 的记录必须能由行动闭环产生，也允许脱离 DO 单独创建，这是更明确的产品差异。

## 参考三：Cosmos

- 官方入口：[Cosmos](https://www.cosmos.so/)

### 可见特征

- 以图片、灵感和收藏为主，界面尽量让视觉内容占据主要面积。
- 内容浏览不像传统社交信息流，标签和互动控件被压低。
- 大量留白、图片比例变化和弱边界，让页面更接近视觉档案而非卡片网格。

### 对 DO 的借鉴

- “发现”应先让人产生想试试的冲动，再提供带回 DO 的动作。
- 图片比例和内容节奏可以变化，不必每条内容都套同一张卡片。
- 社交感可以来自共同的生活灵感，而不是点赞数和评论数。

### 避免抄袭

- 不复制 Cosmos 的黑白配色、网格比例、收藏机制或品牌字体。
- DO 的发现内容需要服务行动转化，而不是变成纯灵感收藏站。

## 参考四：Are.na

- 官方入口：[Are.na](https://www.are.na/)

### 可见特征

- 以“收集和连接想法”为核心，弱化算法信息流和社交指标。
- 内容块可以是图片、文字、链接等，用户通过排列形成自己的上下文。
- 视觉上不追求每个元素都被包装成商业卡片，内容之间的关系本身就是结构。

### 对 DO 的借鉴

- DO 可以允许一个念头先以松散状态存在，再逐步变成行动或记录。
- 记录和发现之间可以通过“带回 DO”建立关系，形成个人上下文，而不是简单收藏。
- 非标准化内容块有助于保留真实生活的差异。

### 避免抄袭

- 不照搬频道、块状画布或其协作社区模型。
- DO 仍需有明确的“一步行动”引导，不能让开放结构重新制造犹豫。

## 参考五：Apple Dynamic Island / Live Activities

- 官方说明：[Dynamic Island](https://developer.apple.com/design/human-interface-guidelines/live-activities)
- 官方设计资源：[Human Interface Guidelines - Live Activities](https://developer.apple.com/design/human-interface-guidelines/live-activities)

### 可见特征

- 一个很小的系统对象可以在不同状态中展开、收缩和改变信息密度。
- 状态变化通过形态连续性表达：用户知道同一个对象正在发生变化。
- 重要信息在需要时出现，平时不占据整个界面。

### 对 DO 的借鉴

- DO 图标可以成为持久的核心对象：闲置时是入口，输入时是容器，行动中是状态指示，记录后是确认。
- 形态变化比“打开弹窗”更适合建立一体感。
- 导航可以由核心对象触发，而非永久占据底部空间。

### 避免抄袭

- 不复制胶囊形状、黑色系统浮层或 iOS 动态岛动画曲线。
- DO 的对象必须围绕“念头、行动、记录”设计独有状态，不做系统 UI 仿制品。

## 参考六：Apple Photos 的 Memories / Years 叙事

- 官方入口：[Apple Photos](https://www.apple.com/ios/photos/)
- 设计语境：[Apple Photos User Guide](https://support.apple.com/guide/iphone/view-photos-and-videos-iph3d267610/ios)

### 可见特征

- 通过时间、照片和自动编排，让普通生活形成可回看的叙事。
- 照片是主体，控件尽量不打断观看节奏。
- 回看行为带有“翻阅”和发现感，而不是查看数据。

### 对 DO 的借鉴

- 记录页可以使用“生活影集”隐喻，但不必做拟物化翻页。
- 记录编排应重视图片尺寸、空白和出现节奏，让平凡片段有被认真对待的感觉。
- 可以提供自动生成的分享片段，但分享应是记录完成后的副作用，不是首要目标。

### 避免抄袭

- 不复制 Memories 的自动影片、字体、照片分组和系统转场。
- DO 的核心不是回忆算法，而是把“刚刚发生的行动”留下来。

## 参考七：非传统导航模式

### Arc Browser - Command Bar / Spaces

- 官方入口：[Arc](https://arc.net/)

Arc 将大量导航和空间切换收进侧边栏、命令入口和上下文区域，说明导航不一定需要固定底部 Tab。DO 可借鉴“内容优先，工具按需出现”，但不应复制浏览器侧栏。

### Apple Vision Pro - Spatial UI

- 官方入口：[Apple Vision Pro](https://www.apple.com/apple-vision-pro/)

Spatial UI 通过层级、景深和环境关系组织界面，而不是堆叠卡片。DO 在 H5 中不应做 3D 仿真，但可以借鉴“前景动作突出、背景内容退后”的层次关系。

### Instagram Stories

- 官方入口：[Instagram Stories](https://about.instagram.com/features/stories)

Stories 证明了全屏单片段、轻触切换、内容优先的浏览方式很容易理解。DO 可借鉴单片段的沉浸节奏，但必须避免点赞、关注、连续刷屏等社交压力机制。

## DO 应形成的独有组合

| 参考启发 | DO 的独有转化 |
| --- | --- |
| Journal 的私人叙事 | 记录的是行动发生后的真实片段 |
| Day One 的长期档案 | “已记录”取代完成率和打卡压力 |
| Cosmos 的视觉灵感 | 发现内容最终导向“我也想试试” |
| Are.na 的上下文关系 | 念头可以松散存在，再被具体化 |
| Dynamic Island 的形态连续 | DO 对象贯穿输入、行动和记录 |
| Photos 的生活编排 | 普通经历也能形成有质感的一页 |

## 建议的视觉实验顺序

1. 先做一个单场景首页：一个视觉主体 + 一个 DO 核心对象 + 一个念头输入动作。
2. 再做对象的四种状态变形：idle、composing、acting、recorded。
3. 最后把记录和发现接入同一套空间，不先做完整导航系统。

这样可以先验证“眼前一亮”和“一体感”，再决定是否扩展为完整 H5，而不是继续在旧页面上累加组件。

## 参考与抄袭边界

- 可借鉴：信息层级、内容节奏、状态连续性、留白、动效目的、导航出现时机。
- 不可复制：品牌 Logo、字体组合、具体图标、摄影素材、文案、独特动画曲线、页面逐像素布局。
- DO 最重要的差异化不是“看起来像哪个产品”，而是把模糊念头转成一个可以立即开始的动作，再把真实经历编排成个人记录。
