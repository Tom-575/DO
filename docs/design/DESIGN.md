# DO 设计规范

> 状态：当前生效。2026-09-13 依据 `prototypes/first-loop` 的实际实现重写，取代此前所有设计文档（DESIGN_DIRECTION、DESIGN_CONCEPT_V2、DESIGN_GRILL、HANDOFF_RESTART，见 git 历史）。
>
> 上位文档：`docs/intent.md` 管价值判断；`docs/CONTEXT.md` 管术语与已确认决策；`docs/PRD.md` 管范围。本文档与其冲突时，以上位文档为准。

## 1. 设计判断（不变量）

继承自 intent.md，任何视觉与交互决策不得违背：

- 开始优先于规划完整；清晰优先于丰富；真实优先于包装；低压力优先于高控制。
- 页面永不出现：完成率、连续 streak、点赞/评论/关注、打卡焦虑、励志口号。
- "已记录"描述记录生命周期，不等于"已完成"；做得不好、中途停止同样值得记录。

## 2. 现状基线（as-built）

**技术形态**：React 19 + Vite + Motion + Phosphor Icons，单文件 `app.jsx` + `styles.css`；状态仅驻留内存，刷新即失；无 AI、无持久化。

**载体**：手机优先（≤520px 全屏铺满）；桌面显示 430×900 圆角手机框居中于灰底。

### 2.1 信息架构

```text
底部 Tab 栏（今天 | 回忆），无其他全局导航
├─ 今天：大标题（实时日期 + 「今天」+ 头像按钮）
│   ├─ DO 入口区：主句 + 副句 + DO 按钮 + 记录次入口
│   └─ 最近的 DO：主推荐 + 备选 + 圆形 disclosure 展开区（候选上限 3；回收行弱化置底）
├─ 回忆：纵向记录流（真实数据倒序；空状态两行居中）
├─ 输入页（点 DO → push）：全屏专注输入
├─ 行动页（输入 → push）：最小行动 + 换一个 / 改念头 + 意向三选 + 现在开始 / 先放着
└─ 记录页（记录次入口 → push）：新的记录（文字 / 图片 / 关联 DO / 帮我整理 / 保存）

外观设置：头像按钮 → 底部 Sheet（明暗 / 背景 + AI 配置 + 数据导出导入）
```

探索页、个人页、底部导航之外的菜单均不存在。

### 2.2 核心交互流

1. 今天页点 DO 按钮 → 推入全屏输入页。
2. 输入任意文字 → 「继续」或右下角圆形发送钮 → 行动页。
3. 行动页展示：用户原话 + 一个最小行动（做什么 / 预计时长 / 停止条件）。
4. 「现在开始」或「先放着」→ 回今天页。

## 3. 视觉系统

### 3.1 色彩

明暗是两套各自授权的 token 体系，不是机械反色：

| Token | Light | Dark |
|---|---|---|
| --bg | #f2f2f7 | #000 |
| --surface | #fff | #1c1c1e |
| --text | #1c1c1e | #f2f2f7 |
| --secondary | #68686e | #aeaeb2 |
| --tertiary | #8e8e93 | #8e8e93 |
| --accent | #ff6b35 | #ff7446 |

- 单一强调色（珊瑚橙）承担全部可交互提示，不引入第二强调色；状态变化只用透明度和亮度。
- 分隔线用半透明色（Light `rgba(60,60,67,.18)`），不使用实色灰。

### 3.2 字体与排版

- 系统字体栈（-apple-system / SF Pro Text），中文回退系统默认。
- 标题一律负字距（-0.035 ~ -0.045em）。
- 字阶：页大标题 36 / 区标题 27 / 行动页主标题 34 / 正文 15–16 / 辅助与元信息 13 / Tab 标签 10。
- 大标题左对齐；日期、副句等元信息退为 13px secondary，不与主标题竞争。

### 3.3 形状与材质

- 圆角：主按钮 14–16 / 列表与卡片 13–15 / Sheet 顶部 24 / 手机框 46。
- 按钮一律无边框；Tab 栏与导航栏用 `blur(20–22px)` 半透明背景。
- 阴影只给主按钮和浮层；列表结构靠分隔线，不靠卡片边框。

## 4. 组件规范

- **DO 按钮**：全宽圆角主按钮，accent 底白字；左侧 "DO"（28px / 750）+ 13px 副标，右侧箭头；按下 `scale(.985)` + 加深。
- **inset 列表行**：56px 高，左文字（max-width 86%）右箭头；组内行间 1px 半透明分隔线；展开/收起用 30px 圆形 disclosure 按钮（chevron，展开旋转 180°，保留 aria-label）。
- **行动 meta 卡**：18px 内边距圆角卡，两行——预计时长、停止条件，15px secondary。
- **记忆条目**：时间行（20px 日期 + 13px 时间）→ 4:3 图片（15px 圆角）→ 正文（16px / 1.55）；纯文字条目包 surface 卡。
- **底部 Tab 栏**：84px 高，图标 23–24px + 10px 文字；选中 accent，未选中 tertiary。
- **外观 Sheet**：底部上滑 + 半透明 scrim；分组标签 13px secondary；选项按钮 46px 高、选中态 accent 描边 + 10% accent 底。
- **记录页（新增记录，2026-09-13 as-built 固化）**：
  - 入口：今天页 DO 按钮下方一行次入口「记录一下刚才做的事」+ 箭头，secondary 灰阶，明显弱于 DO 主按钮；点击 push 进记录页。
  - 导航栏：标题「新的记录」，左上返回箭头——直接返回，草稿不保留、无确认（低压力原则）。
  - 主输入：大号自动增高 textarea，占位「做了什么，就写什么」；此为用户原话，任何情况下不被覆盖。
  - 帮我整理：文字区下方的 accent 文字按钮；点击调 `refineRecord`（草稿态对象），结果填入「整理版」surface 卡文本域，直接可编辑；AI 只在此按钮触发，加载中显示「整理中…」，失败行内提示「整理没成功，稍后再试。」。
  - 图片：三列网格，添加格显示计数 n/9，`file input` 多选，Blob 直存；缩略图可单张 × 移除。
  - 关联 DO：卡片区域；默认推荐最新「待记录」DO（带「推荐」角标），可 × 取消、可展开列表手选任意待定/待记录 DO；无候选时整块隐藏；关联不阻塞输入；保存带 linkedDOId 时该 DO 自动变「已记录」。
  - 保存：底部主按钮「保存」，文字与图片全空时禁用；成功后切到回忆页。

## 5. 动效规范

- 页面切换：**进入有动效、切换即替换**（2026-09-13 决策）。motion 的 `AnimatePresence` 退出动画在部分嵌入式 webview 中永不结束、会卡死切页，故页面渲染不依赖退出机制；进入动效由各页面根节点的 `initial → animate` 承担（push 页：x 18% 位移 + 透明度，spring stiffness 360 / damping 34；首页 Tab 切换：0.18s 透明度渐变）。
- 展开收起：height auto 0.22s（展开动画；收起为立即收起，同上原因）。
- Sheet：0.28s `cubic-bezier(.2,.8,.2,1)` 上滑 + scrim 淡入 0.2s。
- 全局响应 `prefers-reduced-motion`（reduce 时时长归零、禁用动画）。
- 禁止：弹跳、旋转、无限漂浮等无物理意义的动效。

## 6. 文案规范

- 直接、可操作，不带产品腔与鸡汤（沿用 GRILL 确认结论）。
- 当前锚点文案：主句「现在想做什么？」；副句「先写下来。DO 会把它变成可以开始的一步。」；输入页占位「想到什么，就写什么」；辅助句「不用先想清楚目标或计划。」
- 记录示例语气参考 intent.md 的"俯卧撑"条目：事实 + 原话 + 允许不完美，不写励志体。

## 8. 下一阶段设计任务（记录闭环）

> 状态更新(2026-09-13):本节 1–7 项已随 change `mvp-record-loop-h5` 实现并通过浏览器走查,
> 设计细节已固化进 §2.1 与 §4;第 4 项分享维持后置。剩余待办转入 §7 第 6 条(边界设计)。

以下依赖 `docs/CONTEXT.md` 已确认的边界，进入 Build 前需先过 Plan / Design gate：

1. **数据与状态**：DO 三态状态机（待定 / 待记录 / 已记录）；localStorage 持久化，刷新不丢。
2. **记录入口**：首页次入口 + 全局创建；先表达后整理，「帮我整理」由用户主动触发，AI 不实时改写；核心动作叫「保存」。
3. **关联**：创建记录时可选关联 DO / 接受推荐 / 跳过；推荐必须可取消；不阻塞输入。
4. **分享**（后置，2026-09-13 决定本轮不做）：单张图文卡片（封面图 / 标题 / 正文摘要），从记录生成、可编辑；保存为私人记录，分享是之后的独立动作。MVP 闭环止步于：念头 → 最小行动 → 记录 → 保存 → 回忆回看。
5. **首页信息架构**：主 DO 推荐 + 备选 1 条 + 收起区（候选上限 3）；待定超 24h 自动回收进历史清单。
6. **行动意向**：愿意去做 / 不想做了 / 暂时不决定；允许不选直接执行并回来记录。
7. **AI**：接入真实 AI，行为契约见 `docs/DO-PROMPT.md`；记录保留用户原话与 AI 整理版两份，整理结果直接进入可编辑状态。
