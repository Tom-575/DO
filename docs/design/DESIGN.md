## 1. 设计判断（不变量）

继承自 intent.md，任何视觉与交互决策不得违背：

- 开始优先于规划完整；清晰优先于丰富；真实优先于包装；低压力优先于高控制。
- 页面永不出现：完成率、连续 streak、点赞/评论/关注、打卡焦虑、励志口号。
- "已记录"描述记录生命周期，不等于"已完成"；做得不好、中途停止同样值得记录。

## 2. 现状基线（as-built）

**技术形态**（2026-09-16 按当前实现修订）：TypeScript + React 19 + Vite + Motion + Phosphor Icons，代码在 `src/`（`pages/` / `components/` / `store/` / `lib/`，各页面样式就近分文件）；DO / 记录 / 图片存 IndexedDB，设置与 AI 配置存 localStorage，刷新不丢；AI 走 `lib/ai` adapter 直连 OpenAI 兼容接口，无 key 时回落 mock；无后端、无账号、无云同步。

**载体**：手机优先（≤520px 全屏铺满）；桌面显示 430×900 圆角手机框居中于灰底。

### 2.1 信息架构

```text
底部深色胶囊导航三槽（今天 | 开始 | 痕迹；图标 + 10px 标签，选中项套白胶囊）；「我的」不在此列，只由今天页右上头像进入，无其他全局导航
├─ 首页横滑容器（2026-09-16）：今天与痕迹是一页一张的横向分页器，左右滑动即切换，
│   与 Tab 栏双向同步；两页各自保留纵向滚动位置
├─ 出发（onboarded 为 false 时的一整屏）：满幅摄影 + DO 字标 + 开始
├─ 今天：kicker（英文日期）+ 「今天」+ 头像（进「我的」）
│   ├─ 墨黑念头卡：kicker + 念头输入 + 蜜桃胶囊「DO」（不放示例 chip，2026-09-19；按钮由「帮我找到第一步」改名，2026-09-20）
│   ├─ 正在进行：主卡（封面缩略 + 念头 + 已经试了 N 次 / 最长时长 + 大号次数）+ 「全部」展开更多
│   └─ 最近的痕迹：最近 2 条（左侧结果色条 + 正文 + 日期 · 结果）+ 「看全部」切痕迹页
├─ 痕迹：居中 kicker「YOUR TRACES」+ 「痕迹」；统计卡（次真实尝试 / 做完了 / 中途停下）+ 时间线卡片流（2026-09-17 用户决定去掉分类筛选）
├─ 对话页（念头卡 → push）：对话式规划（AI 必要时澄清 ≤2 轮 → 单一最小行动），进页即自动发出首页那条念头
├─ 第一步页（对话落定 / 正在进行卡 → push）：黑卡最小行动 + 时长档位 **5 分钟 / 15 分钟 / 自定义**（1–90，2026-09-20）+ 底部三选（无「换一个建议」，2026-09-17 决定不复刻）；左上返回 = 放弃这一步回今天页（2026-09-19）
└─ 记录页（底部「开始」槽 → push）：「这次怎么样？」结果四选（可跳过）+ 原话卡 + 工具行（加照片 / 记录时间 / 帮我整理）+ **「关联一个念头」独立一行**（2026-09-20：不再混在工具行里；未关联显示入口、已关联显示念头原文，候选列表跟随入口就地展开）+ 生成我的记录（草稿自动暂存；痕迹页点条目进入为编辑态）

痕迹条目（#17 分区响应、#18 封面化；V2 换卡面）：有图 = 满宽 4:3 封面 + 白卡正文，无图 = 米色纯文字卡；点图片 → 全屏查看器（黑底，横滑切换全部原比例图，页码 n/N，X 关闭，铅笔进编辑，单图也进）；点文字/其余 → 编辑态；卡片右下角导出按钮 → 分享卡整屏（2026-09-17 V2：满幅封面 + 徽章 + 时长大字 + 保留原话开关 + 分享/只保存图片）

我的（**点头像** → push 一整屏；底部导航不含此入口）：明暗 / 背景 + AI 配置 + 数据导出导入（草稿模型不变）
```

探索页、个人页、底部导航之外的菜单均不存在。

### 2.2 核心交互流

1. 今天页点「DO」：**已接入 AI**（`baseURL` / `model` / `apiKey` 三项齐全）→ 推入对话式输入页；**未接入** → **跳过对话**，直接把念头带进行动页（2026-09-20）。此时行动由 `lib/mock` 的关键词模板生成——与对话落定后走的是同一个函数，少的只是那一步关键词提问。
2. 输入念头发送 → AI 仅当「不同解释会明显改变行动」时回一个简短问题（附建议选项，可自由回复），最多 2 轮；落定后自动进入行动页。
3. 行动页展示：用户原话 + 一个最小行动（做什么 / 预计时长 / 停止条件）。
4. 行动页底部三选「马上做 / 等等 / 不想做了」任一 → 回今天页。
5. 行动页左上返回 = 放弃这一步回今天页（2026-09-19）。**不保留「回对话页」出口**：对话页是一次性动作（进页即自动发出首页那条念头），退回去只会重跑一遍并把用户弹回行动页；要改念头，回首页黑卡更直接。
5. 记录：中央「+」→ 记录页（草稿自动暂存，重进恢复）；保存 → 回忆页；点条目图片 → 全屏查看器，点文字 → 编辑态（改文字/图片/关联，关联变更联动 DO 状态）；右上角下载按钮 → 卡片预览 → 保存 PNG。

## 3. 视觉系统

### 3.1 色彩

明暗是两套各自授权的 token 体系，不是机械反色：

V2（2026-09-17）换成暖色体系：

| Token | Light | Dark |
|---|---|---|
| --bg | #f7f5f2 | #121110 |
| --card | #ffffff | #1c1a18 |
| --text | #0f0f0f | #f5f1ec |
| --secondary | #8c867d | #a49d94 |
| --hairline | #ece8e2 | #2b2724 |
| --peach | #f2c9b4 | #f2c9b4 |
| --terracotta | #c97b58 | #d98d66 |

- 蜜桃是唯一填充强调色（主按钮 / 选中态 / 徽章）；陶土只用于数字与点缀。
- 分隔线用暖发丝线；状态变化仍只用透明度与亮度。


### 3.2 字体与排版

- 中文走系统字体栈；拉丁数字与 kicker 走超窄体 `--font-display`（Bebas Neue，离线回落 Arial Narrow）。
- kicker：全大写 + `letter-spacing: .2em`，13px，只出现在页标题上方与卡片内的引导语。
- 巨型数字（10 MIN、次尝试、统计）用 `.figure`：字重 400 + 单位缩到 0.34–0.42em 并染蜜桃/陶土。
- 中文标题负字距（-0.02 ~ -0.035em）；字阶：页大标题 34 / 第一步页标题 28 / 区块标题 17 / 正文 15–16 / 元信息 11–13 / Tab 标签 10。
- 大标题左对齐；日期、副句等元信息退为 13px secondary，不与主标题竞争。

### 3.3 形状与材质

- 圆角：主/次按钮与 chip 一律胶囊（999px）/ 白卡 24 / 墨黑大卡 28 / 分享卡 22 / 手机框 46。
- 按钮分两层：墨黑填充（`.primary-action`）、蜜桃填充（`.pill-peach`）、白描边（`.pill-outline`）、弱文字（`.quiet-action` / `.text-action`）。
- 墨黑大卡承担「当前最重要的一件事」（念头 / 最小行动 / 分享卡）；白卡承担列表与正文，两者不混用。
- 阴影只给浮起的黑卡、底部导航与浮层；白卡在亮色下用发丝线描边界，不叠阴影。

## 4. 组件规范

- **DO 按钮**：全宽圆角主按钮，accent 底白字；左侧 "DO"（28px / 750）+ 13px 副标，右侧箭头；按下 `scale(.985)` + 加深。
- **inset 列表行**：56px 高，左文字（max-width 86%）右箭头；组内行间 1px 半透明分隔线；展开/收起用 30px 圆形 disclosure 按钮（chevron，展开旋转 180°，保留 aria-label）。
- **行动 meta 卡**：18px 内边距圆角卡，两行——预计时长、停止条件，15px secondary。
- **记忆条目**：时间行（20px 日期 + 13px 时间）→ 4:3 图片（15px 圆角）→ 正文（16px / 1.55）；纯文字条目包 surface 卡。
- **底部导航（V2 三槽深色胶囊，2026-09-17 修订，取代 2026-09-16 的「与页面一体」Tab 栏）**：墨黑胶囊（圆角 999，左右各留 16）三等分三槽——今天 / 开始 / 痕迹；每槽图标 + 10px 标签，选中项套白胶囊（`layoutId` 共享布局动画平移），未选中 50% 白。今天 / 痕迹是分页槽（保留 aria-label 与 `aria-current`）；「开始」（圆形 +）是一次性动作槽，打开记录页（容器变换的圆形原点），按下反馈只用透明度——transform 会带偏白胶囊的测量位置。**不含「我的」槽**：今天页右上头像已是它的入口，底部再放一个是重复（2026-09-17 用户决定）。
- **外观页**（2026-09-16 修订：由底部 Sheet 改为**一整屏**）：导航栏「外观」+ **左侧 ✕（丢弃）右侧 ✓（写回）**——用图标而非文字，因为全站导航栏本来就只有图标（返回箭头 / 关闭），文字按钮会让这一屏显得是拼上去的；内容是一列分组，分组标签 13px secondary；选项按钮 46px 高、选中态 accent 描边 + 10% accent 底。
  - **改动走草稿，不即时生效**（2026-09-16 用户要求「避免改了就改不回去了」）：打开时把 `theme/background/ai` 拍一份快照作为草稿，面板内所有改动只改草稿；「确认」把草稿写回 store 再离开，「取消」直接离开。这样**「取消」是真正的空操作**（不写回、也不做反向 dispatch），不存在"撤销失败"的状态。离开只有这两个出口，所以不会有"改动悄悄丢了"的路径。
  - 代价：选择时**看不到自己选的效果**（主题不预览、背景被不透明页面挡住），只有确认后才应用。选项本身用图标与色块自解释；若日后要「边选边看」，需改成实时预览 + 取消回滚（代价是改动会先落进存储）。
  - 数据分组**不在草稿内**（2026-09-16 修订）：导出是只读，恢复点下去即写入、不受 ✕ 影响。这一点**标在分组标签右侧的「立即生效」tag 上**（`<span class="group-label">数据<em class="group-tag">立即生效</em></span>`），而不是写成页尾的一句免责说明——标注要出现在动作**之前**，贴在分组自己身上，用户在做选择时就能看到边界在哪。
  - 动效见 §5（与 `+` 号同一套圆形裁切，从头像那个圆展开，取消/确认都按相反曲线收回）。
- **记录页（新增/编辑记录，2026-09-13 二期 as-built 修订）**：
  - 入口：底部 Tab 栏中央「+」新建；回忆页点条目进入编辑态（导航栏「编辑记录」、按钮「保存修改」）。
  - 草稿：新建态内容变更即自动暂存 IndexedDB（含图片 Blob），重进静默恢复并显示「已恢复上次未保存的草稿」；保存或清空后移除。编辑态不启用草稿。
  - 主输入：surface 底衬圆角卡内的自动增高 textarea，占位「做了什么，就写什么」；此为用户原话，任何情况下不被覆盖。
  - 帮我整理：accent 文字按钮，新建与编辑态均可用；结果填入「整理版」surface 卡，直接可编辑；失败行内提示。
  - 图片：三列网格，计数 n/9，多选；选图即压缩（原图 >300KB 时长边压至 1600px、JPEG 0.85）；缩略图可 × 移除。
  - 关联 DO：默认推荐最新「待记录」DO（新建态）；编辑态候选包含当前已关联的 DO（即使已变「已记录」），否则无法查看/取消关联。关联变更联动：原关联回退「待记录」，新关联转「已记录」。
  - 保存：底部主按钮；成功切回忆页并清草稿。
- **分享卡（#14；V2 换深色语言，封面维持 #16 原比例不裁切，2026-09-17）**：一整屏深色（`.share-page`，z-index 40）+ 顶部「把这次留下」+ ✕；卡片本体 canvas 手绘（预览即导出物）：深色底 + 「第 N 次尝试」徽章（无关联 DO 不画）+ 封面**按原比例完整绘制**（高度随图伸缩，不裁切）+ 文字块在其下方（`{分钟} MIN` → 正文 → 关联念头 → 签名），文字不压图；底部「保留我的原话，不做修饰」开关（默认开）+ 「分享」（Web Share，缺 `canShare` 时回落保存并说明）+ 「只保存图片」+ 「只留给自己，不分享」。以下为 #14/#16 原始约定：回忆条目右上角下载按钮 → 全屏遮罩内 canvas 预览（即导出物，所见即所得）+「保存图片」。卡片 340px 宽 2x 分辨率，浅色固定：日期 → 首图原比例圆角封面（不裁切，高度随原图比例，暂不设上限；无图纯文排版；封面加载失败出 1:1 占位）→ 正文（整理版‖原话，一字不改）→ 页脚（关联念头行 + 「DO · 不完美，也可以出发」）。canvas 手绘导出（html-to-image 在嵌入式 webview 挂起，弃用）。
- **全屏图片查看器（#17，2026-09-14 as-built；#18 列表封面化）**：回忆列表只展示首图缩略（4:3 裁切，#7 既有规则；原比例只在查看器与卡片），多图条目右下角标显示总张数（半透明胶囊 + Images 图标）；点封面进入查看器，应用内 absolute 遮罩（z-index 40，同 card-overlay 模式）。黑底；顶部 X 关闭 / 页码 n/N / 铅笔进编辑；scroll-snap 横滑一图一页（`scroll-snap-stop: always`），单图也进；键盘 ←/→/Esc，滚轮纵向分量转横向；`touch-action` 分层（遮罩 none / 轨道 pan-x）防触摸穿透；reduce-motion 跳过平滑滚动；封面加载失败出占位块（仍可点进查看器翻其余图）。不做缩放/排序/封面选择（留待后续）。
- **对话输入页（#15，2026-09-13 as-built）**：气泡对话流——用户右对齐 accent 气泡、AI 左对齐 surface 气泡；提问附建议选项 chips（点选即发送，也可自由输入）；思考中「想一下…」；返回箭头放弃整段对话。红线：提问 ≤2 次（adapter 三层强制），产出恒为单一最小行动，DO.thought 恒为用户原话。

## 5. 动效规范

> 2026-09-16 两次重写。第一次是把动效从零散实现收敛为「一套参数 + 一张清单」；
> 第二次（用户反馈「不是幅度问题，是交互动画本身」）确立了下面三条原则，并据此**改掉了方向与原点**。
> 参数集中在 `src/lib/motion.ts`，新增动效从这里取，不要各页自造曲线。

### 5.0 三条原则（写在参数前面，比参数重要）

1. **原点**：新界面必须**从被点的那个控件长出来**。没有来源控件的页面（如输入 → 行动）才允许整页进入。
   - **结果的形态决定动效的形态**：
     - 结果是**一整屏** → **裁切铺满**：起点 = 控件形状的 `clip-path`，内容原地不动只被露出来。实现：`lib/screen-origin.ts` 在点击处理器里同步量下控件矩形（必须在卸载前量），`lib/use-expand-transition.ts` 用它做 `clip-path` 起点。用于 记录页 / 输入页 / 行动页 / 查看器 / 回忆条目→编辑 / **外观页**。
     - （试过并弃用：macOS 式窗口缩放——起点 = 位移 + 缩放，内容跟着放大且会变形，一整屏的目标下不如裁切。）
   - **形状必须守恒**（2026-09-16 用户纠正：「+ 号是圆形的，那么展开和回收应该也是圆形的」）：**真正是圆的控件**（今天页头像，44×44）声明 `shape: 'circle'`，**起点与终点都必须是 `circle()`**（`circle(22px at cx cy)` → `circle(到最远角 px at cx cy)`），全程是一个圆在长大；矩形控件才用 `inset(... round ...)`。若起点用 `circle()`、终点用 `inset()`，浏览器无法插值会直接跳变；而用 `inset(... round 22px)` 两端插值会让圆角在途中**退化成圆角方块**。
   - **背景要「退后」**：有 push 屏盖上来时，首页模糊 + 轻微放大（`.main-page.receded`），前景才是压上来的而不是贴上来的。展开用 .42s（与铺开同步）、收回用 .34s（与收回同步）——收回时长靠 `:has(.bloom-out)` 让背景直接感知「前景在退」，不必把动画阶段同步进 store。
   - 反面例子（已废弃）：① 点 `+` 号、记录页却从屏幕右侧自己滑进来；② 点头像、面板却从屏幕底部滑上来——**换入场动画救不了错的形态**：从头像弹出的东西不该是个底部抽屉。
   - 反面例子（通用化的陷阱）：给所有可点元素套同一个「按下缩小到 0.94」——它不表达任何东西，只是告诉用户「我注册了点击」。按下反馈可以统一，但**位移动效必须逐个设计**。
2. **方向 + 跟手**：方向要和触发它的手势一致，而且**位移必须由手势本身驱动**。
   - 切页是横向手势 → 切页的位移动效只能横向。
   - **禁止「到位之后再补一段动画」**：切页的位移全部交给原生 `scroll-snap`（手指走到哪页面就到哪）；在页面停稳后反弹一下标题或内容，会被读成「页面重新刷新了一次」（2026-09-16 用户反馈「不跟手，像重新刷新了页面」）。
   - **区分「静止态」与「运动瞬态」**：想做「弹出去弹回来」时，默认值必须落在**原位**，偏移只能是运动过程中的瞬态。把偏移写进静止态（`animate: active ? 0 : 46`）等于「拉着不放、松手才弹回」，与手势脱钩。
   - 这条同样适用于 tab 状态：**越过中点就立刻翻**，让指示点在手指还没松开时就跟着走；等滚动停稳再翻，手感是断的。
   - **状态与位置要分清是谁在推进**（2026-09-19 补，事故见 #43）：手势驱动时状态跟手、**位置只由手指推进**，此时任何程序化 `scrollTo` 都会打断/取消原生触摸滚动（真机表现是「滑一下就弹回」）；反过来，点 Tab 是状态先动、位置由程序化滚动跟上。`App.tsx` 用 `tabFromGesture` 标记区分这两个来源。
3. **物理**：用弹簧（质量/刚度/阻尼）而不是凑出来的贝塞尔曲线。过冲是阻尼比的结果，不是硬加的夸张效果。
   - 需要「落位后回摆一次」就调低阻尼比，而不是叠一个 keyframe。

### 5.1 硬约束（不得违反）

- **页面切换不使用 `AnimatePresence`**：其退出动画在部分嵌入式 webview 中永不结束、会卡死切页（事故 531b570）。页面切换一律「进入有动效、切换即替换」。
- **浮层只做进入、不做退场**（Sheet / 查看器 / 卡片遮罩同理）：关闭即卸载。需要反向动效时用**定时器驱动**——先播动画、时长走完再切页（容器变换的收回就是这么做的）。
- **按下反馈的缩放，只在元素同时被 motion 驱动时才必须用 `whileTap`**（2026-09-16 发现）：动画结束后内联 `transform` 会继续留在元素上，把 CSS 的 `:active { transform }` 整个盖住——此前列表行与回忆条目的按下缩放因此是失效的。**纯 CSS 按钮（导航栏、主/次行动按钮、卡片与 Sheet 按钮等）没有这个问题，用 `:active { transform }` 更简单，也是 §5.3 写的做法。**
- **循环动画只允许「状态指示」型**（如「想一下…」的呼吸/跳动点），它表达正在处理，不是装饰。禁止旋转、无限漂浮等无物理意义的动效。
- 全局响应 `prefers-reduced-motion`：reduce 时时长归零、`animation` / `transition` 关闭，容器变换直接跳过。
- **首页常驻在 push 屏下方**（`App.tsx` 的 `.main-page` + `.push-layer`）：容器变换裁切出来的部分露出的必须是**真实的上一屏**，否则会露出空白底。首页为此固定 `z-index: 0` 并自建层叠上下文，push 屏在 `.push-layer`（`z-index: 1`）；无 push 屏时首页 `inert` 解除，有 push 屏时 `inert` + `aria-hidden`。
- **磨砂照片只属于首页**（2026-09-16 修正）：`.phone-app.has-background .page` 的半透明 + `backdrop-filter: blur(6px)` 现在只挂在 `.main-page`。push 屏是被导航到的一屏，**必须不透明**——它底下垫着常驻的首页，半透明 + 模糊透出来的是首页内容（一团高斯模糊的鬼影），而且容器变换裁切出的边缘也不干净。

### 5.3 交互动效清单（as-built 2026-09-16）

> **每个交互的动效要按它「做的事」来设计，不是一套通用手法套所有控件**（2026-09-16 用户反馈：
> 「有些交互动画应该是不一样的，就像点击 user 那里的动画也应该是不一样的」）。
> 判断顺序：这个控件**改变了什么**？→ 动效的**起点/终点/形状**都应该指向那件事。

| 交互 | 它做的事 | 动效设计 | 原点 |
|---|---|---|---|
| `+` 号 | 进入全屏新页面 | **一个圆长大铺满整屏** / 收回；起终点都用 `circle()`，全程保持圆形 | 那个圆 |
| DO 主按钮 | 进入全屏输入页 | 从橙色胶囊铺满整屏 / 收回 | 那条胶囊 |
| 回忆条目正文 | 进入全屏编辑页 | 从卡片铺满整屏 / 收回 | 那张卡片 |
| 「最近的 DO」某一行 | 进入全屏行动页 | 从那一行铺满整屏 / 收回 | 那一行 |
| 回忆封面图 | 全屏看图 | 黑色查看器从缩略图扩开 / 收回 | 那张缩略图 |
| **头像（user）** | **打开设置** | **一整屏，和 `+` 号同一套：一个圆从头像长大铺满整屏，点左侧返回再收回**。既不是「从底部上拉的抽屉」，也不是挂在小角落的浮层 | 那个圆 |
| Tab 图标 | 横向换页 | 指示点横向滑动（跟在手势后面） | 手势 |
| 大标题「今天 / 回忆」 | 同上，但它是页面上最轻的元素 | **惯性甩出**：静止永远在原位，被拖动时跟不上、往反方向甩出去，手一停弹回原位 | 手势速度 |
| 圆形 disclosure | 就地展开更多 | 容器高度展开 / 收起 | 不做位移动效 |
| 行动页 | 没有来源控件（AI 回复的产物） | 整页向左推进一格 | 无（流程前进） |

**实现边界**：`lib/screen-origin.ts` 统一负责「按下时同步量下控件矩形」，不在各页重复测量。
**当前只用一种**：裁切铺满（`use-expand-transition`：内联 `clip-path` + CSS transition，收回定时器收尾）。
形状由控件自己决定：`+` 号是圆形按钮，起点就是那个圆；胶囊/卡片/行/头像的矩形决定各自的起点形状。
（试过并弃用的 macOS 式窗口展开已删除，理由见 §5.0。）
- **Tab 栏**：选中态三重表达——变色 + 图标 1.14 倍放大 + **滑动指示点**（两个 Tab 共用 `layoutId` 做共享布局动画，弹簧收尾）。这是布局动画（靠测量驱动），不是退场动画，不涉及 `AnimatePresence` 卡死问题。因此这两个按钮的按下反馈只用透明度：按钮一旦被 transform 缩放，指示点的测量位置会漂。
- **横滑切换**：今天 / 回忆之间左右滑动，由原生 `scroll-snap` 承担位移与吸附（`scroll-snap-stop: always`，一次手势只翻一页），`smooth` 仅用于点 Tab 与程序化跳转。**页面内容不做整块位移**——顶栏与内容都跟着页面框走，不额外偏移（整块偏移会让内容与页面框错位，读作「刷新」）。
- **大标题「惯性甩出」**（`lib/use-swipe-lag.ts`）：只有大标题额外动——偏移量 = 本次滚动事件的位移 × 1.8（上限 ±46px），用欠阻尼弹簧跟随，目标归零时过冲一次即「弹回来」；另有「滚动静默 90ms 收回」兜底，**手指按住不动时标题也在原位**。要害是：**偏移只能是运动瞬态，静止态永远在原位**（2026-09-16 用户纠正：「不应该被拉到最左或最右边，而应该是原位弹出去弹回来」）。
- **Tab 落点判定**：滑动**越过中点立刻翻** tab（指示点因此在手指还没松开时就跟着走）。唯一要挡的是「点 Tab」触发的程序化平滑滚动——它一路上会掠过对侧页，跟着判定会把正在滑向今天的用户又推回回忆；所以用 `PROGRAMMATIC_GUARD_MS`（600ms）的短守卫窗口，用户一旦按下接管手势，守卫立刻作废。
- **首页**：DO 入口区 + 列表区错峰上浮（0s / +0.12s）；行错峰 0.09s；DO 主按钮从 0.86 弹入、悬停抬起、按下回弹；展开区收起/展开都做 height+opacity 0.3s。
- **回忆流**：条目错峰进入（上限 6 项 × 0.09s）+ 上移 28px；封面/缩略图淡入并从 1.04 缩回；整条按压 `whileTap` 内收；导出按钮按下缩放。
- **图片查看器**：遮罩淡入 + 顶栏从上弹落 + 图片从 1.06 缩回；滑动切图沿用 `scroll-snap`。
- **卡片预览**：遮罩淡入 + 卡片从 0.9 / 下移 34px 弹上来（0.44s 带过冲曲线）。
- **对话输入页**：气泡按说话方从各自一侧推入（用户从右、AI 从左）；建议 chip 错峰弹入；「想一下…」是**三个跳动点**；新消息平滑滚到底。
- **行动页**：原话 / 行动内容 / meta 卡 / 底部三选四段错峰（0 → 0.28s）；生成完成后占位标题换成真内容（弹入）；「想一下…」呼吸；按钮由禁用转可用走 0.2s 过渡。
- **记录页**：整理版整块弹入；缩略图与添加格错峰弹入（从 0.7 放大）；关联 DO 区上浮、候选行错峰 + `whileTap`；行内提示弹入。
- **我的（设置页）**：与圆形控件同一套裁切——起点 = 头像那个圆（`circle(22px at ...)`，44px 头像的半径），长大到覆盖整屏；点「取消」/「确认」都按相反曲线收回，播完 340ms 定时器再切页。**「确认」先把草稿写回再离开**，所以收回去的路上露出的首页已经是新外观；「取消」不写回，露出的是原样。
- **背景退后（四种 push 屏共用一个机制）**：`.main-page.receded` → `filter: blur(12px)` + `scale(1.04)`。放大不是为了夸张——全幅 blur 在元素四边采不到内容会淡出一圈，放大一点正好把虚边推出去。展开用 .42s 与铺开同步；收回用 .34s 与收回同步，靠 `.phone-app:has(.bloom-out)` 感知「前景在退」；没有收回动画的路径（如保存记录后直接切回首页）走 .24s 兜底。
- **按下反馈**：`whileTap` 统一 `PRESS_SCALE`；导航栏按钮与纯 CSS 按钮放大到 0.84–0.96；列表行按下给一次 iOS 式背景高亮 + 箭头右移 3px。
- **列表行**：所有 inset 行按下给一次背景高亮（iOS 式），箭头随之右移 2px。
