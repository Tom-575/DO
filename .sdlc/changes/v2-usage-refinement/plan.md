## Problem

真机用起来之后，三处「多余的步骤 / 太弱的信号」暴露出来：

1. **入口名与行为不一致**：按钮写「帮我找到第一步」，但没配 AI 时它打开的对话页只会跑
   `planActionMock` 的关键词提问（"想在哪儿动一动？"），价值低、还多一步。
2. **记录页的关联入口优先级最低**：它和「加一张照片 / 记录时间 / 帮我整理」并排、同为 12px chip，
   而「关联一个念头」是这一页唯一承载语义的动作（决定记录归属哪个 DO、并联动 DO 状态）。
3. **时长档位与 AI 建议打架**：档位是 [10, 30, 60]，大字显示的是 AI 解析出来的分钟数。
   一旦档位与 AI 值对不上（例如档位改成 5/15、AI 说 10），大字写着 10 而两颗胶囊都不高亮，
   用户读不出「这个数字是谁定的」。

## Desired outcome

- 首页按钮叫 **「DO」**；没配 AI 时点它**直接进第一步页**（不再经过对话页）。
- 记录页的「关联一个念头」**独立成一行**，未关联时一眼能看到，已关联时一眼能看到关联了谁。
- 第一步页时长只有 **5 / 15 / 自定义**（自定义由用户输入），**不出现 AI 的建议值**；
  任何时候都有且只有一个档位处于选中态。

## Scope

### In scope

1. `TodayPage`：按钮文案改「DO」；`isAIConfigured` 为假时直跳 `action`，为真时仍进 `input`。
2. `RecordPage` + `record.css`：关联入口从工具行移出，独立成一行；工具行保留其余三个。
3. `duration.ts` + `ActionPage` + `action.css`：档位 `[5, 15]` + 就地展开的自定义输入（1–90）；
   单位统一按分钟渲染；AI 建议时长**吸附到最近档位**决定初始选中项。
4. 文档同步：`DESIGN.md`（§2.1 / §2.2 / §4）、`docs/CONTEXT.md`（已确认边界）、`docs/TODO.md`。
5. `scripts/verify.mjs`：第一步页时长的断言随档位改动更新。

### Out of scope

- `#45` 卡片改版（另属 `v2-device-feedback` 的 Open decisions）。
- 没配 AI 时第一步页的行动来源仍是 `getAction` 关键词模板 —— 本轮只省掉对话那一步，不换生成逻辑。
- 设置页「AI 状态显示」（我提议过、用户未表态）：**本轮不做，另开条目**。

## Constraints

- 不改存储 schema、不改 `docs/DO-PROMPT.md`。
- 已确认决策不回退：`#16` 封面不裁切、三选语义、原话保留、草稿暂存、导入导出全部保留。
- 页面切换仍不使用 `AnimatePresence`；新界面仍从被点控件长出（`captureExpandOrigin`）。
- 时长写库仍是 `action.time` 的人读文案（`大约 X 分钟`），不改数据契约。

## Success criteria

- [ ] 无 AI 配置时，首页点 DO → 直接出现第一步页，全程不渲染 `.input-page`。
- [ ] 配了 AI（三项齐全）时，点 DO 仍进对话页。
- [ ] 记录页工具行只剩「加一张照片 / 记录时间 / 帮我整理」；关联入口独立一行，
      未关联显示「关联一个念头」，已关联显示念头原文，点开仍是原来的候选列表。
- [ ] 第一步页档位为 5 / 15 / 自定义；AI 给 10 分钟时选中 15，不出现「都不高亮」。
- [ ] 自定义输入 1–90 生效，超出被夹到边界，大字与选中态同步。
- [ ] 任何分钟数下都不会渲染 `1.25 HR` 这类半格单位。
- [ ] `npm run typecheck` / `npm run build` / `npm run verify` 全绿。

## Open decisions

- [x] **用户已明确的两条**：入口按钮叫「DO」；**不展示 AI 建议值**（时长档位只有 5 / 15 / 自定义）。
- [ ] **AI 建议时长的归属（假设：吸附到最近档位，可推翻）** —— 用户没直接回答"初始值显示谁"。
  本轮假设：大字恒为**档位值**，AI 的分钟数只用来决定**初始落在哪一档**（10 → 最近档是 15；
  距离相同时取大），因此不存在"AI 值单独占一档"的情况，也就不违背"不要 AI 建议值"。
  备选：完全忽略 AI 时长、恒定默认 5 分钟。**若用户更想要"恒定 5"，撤回即改一行**。
- [ ] **自定义上限 90 分钟（假设，可推翻）** —— 超过 60 仍按分钟显示（`75 MIN`），不出现 `1.25 HR`。
