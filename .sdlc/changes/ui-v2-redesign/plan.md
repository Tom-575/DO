## Problem

现有 UI 是 2026-09-13 按「系统风 iOS 蓝本」写的冷灰系（`--bg #f2f2f7` + 珊瑚橙 `#ff6b35` + 卡片列表），
与用户新拿到的 V2 设计稿差异是**整套视觉语言 + 信息架构**，不是局部换色：

- 冷灰底 → 暖白底（#F7F5F2）；白卡片 → 墨黑大卡 + 白卡混排；
- 珊瑚橙强调 → 蜜桃（#F2C9B4）+ 陶土（#C97B58）双色，强调色从"填充按钮"退到"数字与点缀"；
- 细体系统字体标题 → 超窄体大字（Bebas 风）+ 小写字母间距 kicker；
- 三槽底部 Tab（今天 / + / 回忆）→ 四槽深色胶囊导航（今天 / 开始 / 痕迹 / 我的）；
- 冷启动直接进首页 → 先有「出发」满幅摄影页；
- 「回忆」是纯记录流 → 「痕迹」是**统计 + 筛选 + 时间线**。

同时 V2 稿引入了三个现状数据模型没有的概念：**结果标签**（做完了 / 做了一部分 / 中途停下来了 /
发现不太适合我）、**痕迹分类**（运动 / 音乐 / 生活）、**尝试次数**（第 N 次尝试）。

## Desired outcome

`prototypes/first-loop` 在浏览器里呈现与 6 张设计稿一致的 V2 视觉与版式，
完整闭环（念头 → 第一步 → 做/不做 → 记录 → 痕迹 → 分享卡）在 V2 语言下依然可跑通，
且已确认的产品决策（三选语义、原话保留、帮我整理、草稿暂存、导出 JSON）一个不少。

## Scope

### In scope

1. V2 设计系统：暖白/墨黑/蜜桃/陶土色板、超窄体大字与 kicker 排版、胶囊形状系统、卡片层级。
2. 六屏复刻：出发 / 今天 / 第一步 / 记录 / 痕迹 / 分享卡。
3. 底部导航改为四槽深色胶囊（今天 / 开始 / 痕迹 / 我的）。
4. 「我的」= 现有外观页（明暗 / 背景 / AI / 数据）在 V2 语言下重排，功能不变。
5. 数据契约增量：`MemoryRecord.outcome?`（结果标签，可选）、`AppSettings.onboarded?`（出发页是否已看过）。
6. 痕迹分类：按记录文本 + 关联 DO 念头**推导**（不新增字段、不要求用户打标）。

### Out of scope

- 后端、账号、云同步（产品边界不变）。
- 分享到第三方平台（V2 稿的「分享」只用 Web Share API，不支持则回落保存图片）。
- 多模板分享卡（仍 1 套 V2 模板）。
- 排序 / 封面选择 / 图片缩放（沿用既有后置项）。
- 深色主题按稿重画（V2 稿只有亮色一套；黑夜主题按新色板做等价映射，不额外设计第二套）。

## Constraints

- **不得删功能**：行动三选（马上做 / 等等 / 不想做了）、帮我整理、关联 DO、草稿暂存、导入导出全部保留。
  设计稿未覆盖的功能一律按 V2 语言重排，不静默下架。
- 页面切换禁用 `AnimatePresence`；容器变换 / 原点 / 形状守恒等既有硬约束继续生效（DESIGN §5.1）。
- 手机优先（≤520px 全屏铺满），桌面 430×900 手机框居中。
- 无网络时可用：字体用系统字体栈回落，AI 回落 mock。

## Success criteria

- [x] 六屏版式与设计稿一一对应（色板、层级、圆角、排版语言）。
- [x] 完整闭环在 V2 下可跑通：出发 → 今天写念头 → 第一步 → 现在开始 → 痕迹记录（选结果+写原话）→ 痕迹页看到统计与卡片 → 分享卡导出。
- [x] 已确认决策零回归：三选语义、原话不被覆盖、帮我整理、草稿恢复、导出/恢复 JSON、明暗与背景、AI 配置。
- [x] `npm run typecheck` 与 `npm run build` 通过，无页面错误。
- [x] 记录无 `outcome` 时（旧数据）不展示结果后缀，不崩、不报错。

## Open decisions

- [x] **行动页出口（2026-09-17 用户裁决：方案 C）**：**保留旧结论不动**——三选仍是三档（现在开始 / 先不做改天再说 / 不想做了，第三档降为弱文字按钮），**且不复刻稿里的「换一个建议」**（导航右槽留空）。代价：稿子 03 右上角那个入口在本实现里不存在。
- [x] **分享卡封面（2026-09-17 用户裁决：不裁切）**：原结论保留（#16 原比例不裁切）。V2 语言改为深色卡：封面按原比例完整绘制、文字排在封面下方，不再压图；代价是卡片高度随图伸缩、无法复刻稿中的满幅海报效果。
- [x] **痕迹筛选（2026-09-17 用户裁决：去掉）**：整行筛选 chip 移除，`classifyTrace` / `TRACE_TAGS` 一并删除（不留死代码）；痕迹页只保留统计 + 时间线。
- [x] **底部导航（2026-09-17 用户裁决：不放「我的」）**：稿是四槽，但今天页右上角头像已是「我的」入口，底部再放一个是重复。落地为**三槽**（今天 / 开始 / 痕迹）；「我的」只从头像进。
- [x] **默认背景由山景照片改为「纯净暖白」（已报备）**：V2 首页是暖白底，照片只留在出发页。老用户已存设置不受影响。
